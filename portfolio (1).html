Первый экран, который цепляет

Тёплая палитра, крупная типографика Cormorant Garamond и живое фото. С первого взгляда передаёт атмосферу клуба — лёгкость, движение, общение. Два CTA ведут к тарифам и описанию.

Hero-секция CTA-кнопки Sticky-хедер

О клубе — фото-коллаж + текст

Асимметричная сетка из трёх фотографий создаёт эффект живого альбома. Справа — тёплый текст о миссии клуба. Блок строит доверие и показывает атмосферу изнутри.

Коллаж-сетка Сторителлинг

Расписание на неделю

7-колоночная сетка с цветовым кодированием активностей. Каждый день — своя карточка с названием и временем. Визуально понятно за 3 секунды.

Полноценный календарь на месяц

Отдельная страница с интерактивным расписанием. Фильтры по типу активности, навигация по месяцам, переключатель «Май — Июнь — Июль». Каждое событие кликабельно.

Отдельная страница Фильтры Навигация

Сетка календаря

Цветовое кодирование по типам: танцы, пробежки, книжный клуб, пикники, контент-дни. Бейдж «Сегодня» подсвечивает текущий день. Стрелки для навигации по месяцам.

Галерея + баннер-подарок

Четыре фото в разных пропорциях показывают жизнь клуба. Выше — интерактивный баннер «45+ вещей, которые веселее делать вместе» со ссылкой на чек-лист — отдельная страница с геймификацией.

Фото-сетка CTA-баннер Доп. страница

Тарифы с онлайн-оплатой

Два тарифа — «База» и «Клуб + танцы». Модальное окно с формой заявки, выбором периода (1 или 3 месяца со скидкой) и автоматическим расчётом суммы. Интеграция с Prodamus для оплаты. Бейджи с количеством мест обновляются в реальном времени из Google Sheets.

Тарифные карточки Модальная форма Prodamus Google Sheets Счётчик мест

Задача

Создать лендинг для женского клуба, который передаёт атмосферу тепла, рассказывает о расписании и тарифах, позволяет записаться и оплатить онлайн.

Результат

  • Дизайн-концепция и визуальный стиль с нуля
  • 3 страницы: лендинг + расписание + чек-лист
  • Интерактивный календарь с фильтрами
  • Модальные окна + онлайн-оплата Prodamus
  • Учёт мест в реальном времени (Google Sheets)
  • Welcome-встреча с выбором формата
  • Полный адаптив под мобильные
